Deposit box vault

A locally-encrypted store for private notes and keys.
Everything is decrypted in your browser — nothing is sent anywhere.

This is a demo pattern, not a production secrets manager. The vault file holds ciphertext only — AES-256-GCM, key derived from your passphrase with PBKDF2 (250,000 rounds). A weak passphrase is still guessable offline, so use a long one. See the README before storing anything you actually care about.
