Vault encrypt tool

Turns your secrets into a ciphertext file (vault.enc.json). Run this by opening the file locally in a browser — do not deploy this page alongside real plaintext secrets.

Run this offline, from a local copy of the repo, not from a hosted URL. Everything here stays in your browser tab — nothing is uploaded — but only you can verify that for your own copy. Never paste real secrets into a page you didn't fetch yourself.
